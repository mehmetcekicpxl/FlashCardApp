# FlashCardApp

> **Een interactieve en educatieve mobiele applicatie gebaseerd op flashcards om efficiënter woordenschat of andere concepten te leren en bestuderen.**
In dit project registreert de gebruiker de woorden die hij of zij wil leren en kan dankzij de audiofunctie ook de uitspraak van die woorden leren. Op die manier kan de gebruiker de woorden zowel auditief als visueel onthouden. Bovendien kan hij of zij in verschillende talen leren; er is ondersteuning voor verschillende talen beschikbaar.
Dit project is zorgvuldig ontwikkeld met de nadruk op schone code, schaalbaarheid en een uitstekende gebruikerservaring. De repository bevat alle benodigde broncode, documentatie en configuratiebestanden om direct aan de slag te gaan.

## ✨ Functionaliteiten
- Intuïtieve en gebruiksvriendelijke interface
- De uitspraak van woorden
- Real-time dataverwerking en overzicht
- Veilig en efficiënt beheer van informatie
- Volledig responsief ontwerp voor diverse apparaten
- Uitgebreide documentatie en configuratie

## 🛠️ Gebruikte Technologieën
- **Kotlin, Android SDK**
- **Gradle**
- **Git & GitHub**

## 🚀 Installatie & Gebruik
1. Clone deze repository naar uw lokale machine.
2. Open het project in **Android Studio**.
3. Wacht tot Gradle de synchronisatie (sync) heeft voltooid.
4. Verbind een Android-apparaat of start een Android Emulator.
5. Klik op de **Run**-knop (of druk op `Shift + F10`) om de applicatie te starten.
